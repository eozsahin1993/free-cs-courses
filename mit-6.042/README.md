## Format — proof-based and computational problem sets

The 12 problem sets mix written mathematical proofs (induction arguments, graph theory proofs,
counting identities) with computational/numeric exercises (modular arithmetic, probability
calculations) — all submitted as written work (PDF/scanned or typeset, e.g. LaTeX), not code.
There is no programming component to this course.

## Self-study access

All 12 problem sets and the midterm exam are public PDFs on OCW, and the midterm has solutions
posted. The final exam actually given in Fall 2010 has no solutions published, but three earlier
finals (2004, 2006, 2008) are also posted — this repo points to the 2008 final specifically
because it's the one with solutions, making it the best available self-check for end-of-course
material. OCW also lists 23 recitation sessions, each pairing a short problem set with a
solutions PDF (linked from the course site's "Recitations" page) — a good source of extra
self-graded practice beyond the 12 main problem sets, though they aren't tracked individually per
week here.
